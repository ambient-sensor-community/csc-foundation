# CSC Seedbed: Dreams, Ideas, Questions, and Community Suggestions

This folder is where the Caring Sensor Community captures its imagination.

The Seedbed is a place for early ideas, open questions, possibilities, and reusable lessons. Items do not need to be complete. They do not need to be ready for action. Preserving a promising idea does not mean CSC has committed to pursue it.

All Seedbed entries in this repository are published under **CC-BY-SA**, consistent with CSC's community knowledge license.

---

## Seedbed Categories

Each entry should identify its current type:

* **Seed:** an early idea worth preserving
* **Research thread:** a question that may deserve investigation
* **Proposal:** a possible course of action that has not been accepted
* **Assumption:** an important belief that should eventually be tested
* **Parking-lot item:** something potentially valuable, but not timely
* **Founder Playbook candidate:** a reusable lesson about building CSC or working effectively with AI

An entry may change categories as the idea develops.

A Seedbed entry is not an accepted CSC decision. Accepted decisions are recorded separately in the CSC Decision Log.

**Option 1: Submit a form (easiest)**
Fill out the submission form at: `[form URL: coming soon]`
Your idea will be reviewed and added to this folder by a maintainer.

**Option 2: Submit a pull request (for GitHub users)**

1. Copy the template below into a new file: `seedbed/NNN-short-title.md`
2. Use the next available number
3. Fill in the fields that are useful. Partial entries are welcome.
4. Open a pull request with the title: `Seedbed: [Your Title]`
