# CSC Proposals — Dreams, Ideas, and Community Suggestions

This folder is where the Caring Sensor Community captures its imagination.

A **proposal** can be anything: a project dream, a new sensor idea, a partnership possibility, a funding opportunity, a wish for how the community should work. There is no wrong idea here. Early-stage thinking is welcome — you don't need a complete plan to submit.

All proposals in this repository are published under **CC-BY-SA**, consistent with CSC's community knowledge license.

---

## How to Submit a Proposal

**Option 1 — Submit a form (easiest)**
Fill out the submission form at: `[form URL — coming soon]`
Your idea will be reviewed and added to this folder by a maintainer.

**Option 2 — Submit a pull request (for GitHub users)**
1. Copy the template below into a new file: `proposals/NNN-short-title.md`
   (use the next available number)
2. Fill in the fields as completely as you can — partial is fine
3. Open a pull request with the title: `Proposal: [Your Title]`

---

## Proposal Template

```markdown
**Proposal NNN — [Title]**
*Submitted by: [Name or GitHub handle] · [Month Year] · Status: Dream*

**The idea:**
[Describe the proposal in a few sentences. What is it?]

**Why it fits CSC's mission:**
[How does this connect to trust, consent, accessibility, human connection, or safe aging at home?]

**What it would take:**
[Rough sense of resources — funding, partners, time, skills needed. Estimates are fine.]

**Dream outcome:**
[If this worked perfectly, what would exist in the world that doesn't exist now?]
```
